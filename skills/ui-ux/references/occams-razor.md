# Navalha de Occam

## Princípio

Entre soluções igualmente eficazes, prefira a mais simples.

## Aplicação

- Remova etapas, campos e elementos sem valor.
- Prefira a solução mais direta.
- Evite abstrações desnecessárias.
- Não adicione funcionalidade sem necessidade clara.
- Simplifique antes de adicionar complexidade.

## Exemplo

Se um filtro simples resolve, não crie um construtor de filtros avançado.

## Sinal de violação

- Interface com opções raramente usadas.
- Fluxo com etapas que não agregam valor.
- Solução complexa para problema simples.

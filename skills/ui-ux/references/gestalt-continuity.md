# Lei da Continuidade

## Princípio

Elementos alinhados em linha ou curva são percebidos como contínuos.

## Aplicação

- Use alinhamento para guiar leitura.
- Use continuidade em listas, steppers e fluxos.
- Mantenha direção visual consistente.
- Evite quebras visuais que confundam a sequência.
- Use conectores quando ajudarem a comunicar progressão.

## Exemplo

Em um stepper, etapas alinhadas e conectadas comunicam uma sequência.

## Sinal de violação

- Fluxo sem direção visual clara.
- Itens relacionados com alinhamento inconsistente.

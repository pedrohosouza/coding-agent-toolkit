# Efeito von Restorff

## Princípio

Itens que se destacam visualmente são mais lembrados.

## Aplicação

- Destaque apenas a ação ou informação mais importante.
- Use contraste com intenção.
- Evite destacar vários elementos ao mesmo tempo.
- Use cor, tamanho e peso tipográfico com propósito.
- Destaque avisos críticos e ações primárias.

## Exemplo

Em uma tela de cobrança, o botão “Pagar agora” pode se destacar; os demais elementos devem permanecer neutros.

## Sinal de violação

- Muitos elementos competindo por atenção.
- Tudo parece importante.
- Destaque usado sem relação com prioridade real.

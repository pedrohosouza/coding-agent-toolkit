# Conectividade Uniforme

## Princípio

Elementos visualmente conectados são percebidos como mais relacionados do que elementos apenas próximos.

## Aplicação

- Use linhas, fundos, bordas ou contêineres para reforçar relação.
- Use conectores em fluxos e etapas.
- Use agrupamento visual para conjuntos de informações.
- Não conecte visualmente elementos sem relação.

## Exemplo

Em um stepper, etapas conectadas por linha comunicam sequência.

## Sinal de violação

- Fluxo sem indicação visual de relação.
- Elementos relacionados sem agrupamento perceptível.

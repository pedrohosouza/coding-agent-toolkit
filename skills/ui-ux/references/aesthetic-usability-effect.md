# Efeito estética-usabilidade

## Princípio

Interfaces visualmente agradáveis são percebidas como mais fáceis de usar, mesmo quando a usabilidade real é equivalente.

## Aplicação

- Invista em tipografia, espaçamento, hierarquia e consistência.
- Use design system e tokens.
- Mantenha visual coeso entre telas.
- Não use beleza para esconder problemas de usabilidade.
- Teste usabilidade independentemente da estética.

## Exemplo

Um formulário bem espaçado, com tipografia clara e componentes consistentes, tende a ser percebido como mais simples de usar.

## Sinal de violação

- Interface bonita, mas confusa.
- Estética usada para mascarar fluxo problemático.
- Falta de consistência visual.

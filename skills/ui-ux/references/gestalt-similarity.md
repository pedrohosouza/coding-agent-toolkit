# Lei da Semelhança

## Princípio

Elementos visualmente semelhantes são percebidos como relacionados.

## Aplicação

- Use o mesmo estilo para ações equivalentes.
- Padronize cores, ícones e tipografia.
- Diferencie visualmente apenas quando o significado mudar.
- Mantenha consistência entre estados e componentes.
- Evite estilos parecidos para funções diferentes.

## Exemplo

Todos os botões secundários devem parecer secundários; o botão primário deve ser claramente distinto.

## Sinal de violação

- Ações diferentes com aparência igual.
- Elementos relacionados com aparências inconsistentes.

# Lei da Proximidade

## Princípio

Elementos próximos são percebidos como relacionados; espaço separa grupos.

## Aplicação

- Agrupe campos relacionados.
- Use espaçamento para separar seções.
- Alinhe labels aos seus campos.
- Agrupe ações relacionadas.
- Use espaçamento consistente entre grupos.
- Evite agrupar visualmente itens sem relação.

## Exemplo

Em um formulário de endereço, rua, número, complemento e CEP devem estar visualmente agrupados.

## Sinal de violação

- Campos relacionados espalhados.
- Espaçamento igual entre grupos diferentes.
- Botões de ações distintas agrupados como se fossem uma só ação.

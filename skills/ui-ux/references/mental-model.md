# Modelo Mental

## Princípio

Usuários agem conforme o modelo mental que já possuem do sistema e de produtos semelhantes.

## Aplicação

- Use linguagem, ícones e navegação familiares.
- Alinhe comportamento da interface às expectativas do usuário.
- Evite termos técnicos desnecessários.
- Mantenha consistência entre telas.
- Teste se o usuário entende o que acontecerá antes de agir.

## Exemplo

Um ícone de lixeira deve remover; um ícone de olho deve revelar ou visualizar; um carrinho deve representar compra.

## Sinal de violação

- Ícones ambíguos.
- Termos técnicos no lugar de linguagem do usuário.
- Comportamento inesperado para ações comuns.

# Lei do Fechamento

## Princípio

O cérebro completa formas incompletas quando a estrutura permite reconhecer o todo.

## Aplicação

- Use fechamento em ícones e logotipos.
- Simplifique formas sem perder reconhecimento.
- Evite ambiguidade visual.
- Use espaços negativos com intenção.
- Não sacrifique clareza por minimalismo.

## Exemplo

Um ícone pode usar espaços negativos para sugerir uma forma completa sem desenhar todos os contornos.

## Sinal de violação

- Ícone ambíguo.
- Forma incompleta que não é reconhecida.
- Minimalismo que prejudica compreensão.

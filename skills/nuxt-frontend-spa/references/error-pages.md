# Páginas de erro

## Regras

- Crie `error.vue` com layout consistente.
- Trate `404`, `403` e `500`.
- Ofereça caminho claro de volta para home ou navegação.
- Não exponha stack trace ou detalhes internos.
- Use componentes Nuxt UI para manter consistência visual.
- Use o mínimo de classes Tailwind possível.

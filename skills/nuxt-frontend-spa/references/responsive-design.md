# Responsividade

## Regras

- Mobile-first.
- Use breakpoints consistentes derivados de design tokens.
- Use unidades relativas: `rem`, `em`, `%` e `clamp`.
- Evite pixels fixos para tipografia e espaçamento.
- Verifique múltiplos viewports.
- Prefira componentes Nuxt UI responsivos antes de criar breakpoints manuais.
- Use classes Tailwind apenas para ajustes de layout necessários.
